# Play Console 프로덕션 액세스 진행 기록

> 공개 레포. 테스터 이름·Gmail 명단은 절대 여기 올리지 않는다. 명단은 로컬 `Desktop\하루메이트_테스터모집\` 에만 둔다.

## 상태 (2026-10-06)

| 항목 | 값 |
|---|---|
| 앱 | 하이버디 / `com.harumate.care` |
| 9/30 프로덕션 신청 | 반려 (테스트 기간 부족) |
| 남은 조건 | 검토일부터 12명+ 옵트인 14일 연속 유지 |
| 옵트인 | 12명 (최소치, 버퍼 0) |
| 카운터 트랙 | 비공개 테스트 - Alpha, v6 (1.3.3, 5/1 게시) |
| 대기 빌드 | v7 (1.5.0, 9/6 업로드, 미출시) |
| 재신청 가능 | 10/14경 (기존 12명 유지 시) |

## 절차

1. `테스터모집_담당자용.txt` 를 모집 담당자에게 전달 (15~20명, 안드로이드만)
2. Gmail 명단 수령 → Alpha 트랙 테스터 탭 → 이메일 목록 만들기 `현장사용자` → 저장
3. 담당자에게 등록 완료 통보 + `테스터모집_참여자용.txt` 전달
4. 대시보드 프로덕션 카드에서 옵트인 수 확인
5. 신청 버튼 활성화되면 신청서 작성 (참여 인원 / 실사용자+지원인력 사용 / 피드백 / 반영 내용)

## 하지 말 것

- Alpha 트랙 이메일 목록 체크 해제, 트랙 일시중지, 테스터를 다른 트랙으로 이동 → 카운터 리셋
- 빈 트랙 `하이버디261006`(10/6 생성)에 출시

## 할 것 (심사 가점)

- v7(1.5.0)을 Alpha 트랙에 출시 → 새 테스터가 최신 버전으로 테스트. 옵트인 카운터에 영향 없음
- 테스터 탭 "의견 URL 또는 이메일 주소" 채우기

## 링크

- 테스터 참여: https://play.google.com/apps/testing/com.harumate.care
- 설치: https://play.google.com/store/apps/details?id=com.harumate.care

## 인원 계산

- 조건은 "신청 시점에 12명 이상이 14일 연속 옵트인"
- 기존 12명 유지 → 10/14 신청, 새 인원은 버퍼
- 기존 12명 전부 이탈 가정 → 새 인원 12명 채운 날 + 14일
