## 7. Phase 5: P6 최종 검수 (적출)

1. **5 마일스톤 일정 빡빡** — 풀타임 기준. JY 6 프로젝트 동시 → 8-10주 현실. (JY: "내가 좆뺑이 치는 게 아니라 너가 한다" → 풀타임 OK)
2. **외부 시각 테스트 보류** — JY 알아서. **즉, M5의 외부 검증 점수(86→90)는 self-graded 됨. 외부 평가자 없으면 진짜 90점인지 미입증.**
3. **컨셉「메이트」도 검수 필요** — "메이트" 영문 외래어. P2 룰("외래어 0") 위반. **단 앱 이름 자체가 「하루메이트」라 OK 처리.** 한국어 대안 「짝꿍」 「곁」 「벗」 등 차후 재고려 가능.
4. **카피 검수자 미정** — H1 위반 ("~님/~보세요" 클러스터) JY 단독 검수로 가능한지 의문. 일단 진행, M3에서 외부 1명 영입 검토.
5. **점수 90 self-graded 한계** — 객관 외부 평가 없이는 "indie 출시 후 1년" (70-75) 수준에 도달했다고 보는 게 정직.
